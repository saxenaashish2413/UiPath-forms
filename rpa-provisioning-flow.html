Dynamic lists

Changing Entity clears Policy Role and Deployment Movement and reloads them from EntityPolicyMapping and DeploymentMapping. No per-entity If/Else.

Concurrency-safe ID

The queue enforces unique references. If two requests pick the same number, Orchestrator rejects the second and it takes the next one.

Safe to retry

Existing folders are reused and roles the account already has are kept, so a retried item never duplicates anything.

Configurable API

URL, organization, tenant, scope, timeout and retry come from ApplicationSettings. Client ID and secret come from a credential asset.
